# Dhaka-Bus-Route-Management-System
A prototype console-based Bus Route Management System written in C.
🚌 Dhaka Bus Route Management System (Prototype)

A console-based Bus Route Management System developed in C Programming. This project was created as a prototype to demonstrate how a bus route management application can help users search for buses, view available routes, and estimate travel fares within Dhaka city.

⚠️ Disclaimer
>
> This project is a **prototype** and is intended for educational purposes only.
>
> The bus information, routes, stops, and fare data included in this project are not guaranteed to be 100% accurate or up to date.
>
> Due to the limited availability of complete and reliable bus route information, some routes may be incomplete, missing, or contain inaccuracies. As a result, certain searches may not return the expected results.
>
> This project should **not** be considered an official source of Dhaka bus information.

---

# 📌 Features

- 🔍 Search buses by source and destination
- 🚌 View all available bus routes
- 📍 Display complete route details of a selected bus
- 💰 Calculate regular and student fares
- 🔎 Case-insensitive searching
- 📋 Easy-to-use menu-driven console interface

📖 How to Use

After running the program, a menu will appear.

```
1. Search Bus by Source and Destination
2. Show All Bus Routes
3. Show Route Details of a Bus
4. Exit
```

Search Bus

Enter the starting location and destination.

Example:

```
Starting Location : Farmgate
Destination       : Airport
```

The program will display:

- Available bus
- Route segment
- Regular fare
- Student fare

⚠️ Limitations

This is only a prototype.

Current limitations include:

- Limited number of bus routes
- Some route information may be incomplete
- Bus stop names may contain inconsistencies
- No database integration
- Data is hardcoded into the source code
- Route and fare information may become outdated over time
- No shortest-path or route optimization algorithm
